\## Confirmatory Scientific Outcome

The pre-registered hypothesis that cyclone cases exhibit systematically higher scalar 

phase coherence ($C\_\\phi$) than matched control cases was NOT supported in this cohort. 

The observed distributions substantially overlapped, yielding a negligible effect size 

($g = -0.0037$) and no statistically significant separation.



\## Exploratory Post-Hoc Observation (Hypothesis-Generating)

Several non-cyclonic control cases exhibiting high structural organization (monsoon troughs, 

shear environments, surges) yielded $C\_\\phi$ values comparable to tropical cyclones. 

This suggests the scalar metric $C\_\\phi$ responds to broader atmospheric flow organization 

rather than cyclone-specific vorticity lock. This observation was not part of the 

pre-registered hypothesis and serves exclusively to inform prospective metric designs in Phase 9.
