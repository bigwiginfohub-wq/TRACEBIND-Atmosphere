\### 1. Space and Input Definitions



\* \*\*A Point ($p$):\*\* A single georeferenced spatial coordinate sampling location (e.g., pixel, voxel, or coordinate node).

\* \*\*State Matrix ($I$):\*\* A 2D regular spatial coordinate array derived dynamically from a cropped Region of Interest (ROI) at its native resolution, which is subsequently downsampled to evaluate scale effects.

\* \*\*Attributes:\*\* Each point contains exactly its spatial coordinates, a single scalar intensity value (e.g., Brightness Temperature or Reflectance), and a universal timestamp ($t$). No environmental covariates or secondary atmospheric variables enter the computation pipeline.



\### 2. Topology \& Neighborhood Construction



The neighborhood graph is constructed utilizing Euclidean nearest-neighbor relationships within the georeferenced coordinate system.



\* The methodology supports localized neighborhoods of size $k$.

\* \*\*Scale Constraint:\*\* Operational parameters ($k$ and spatial resolution scaling factor) are determined strictly via an empirical sensitivity matrix rather than arbitrary a priori selection.



\### 3. Localized Reference Distribution (Null Model)



The localized shuffle null model defines the reference distribution against which localized spatial predictability is evaluated. Localized null realizations are generated by randomly sampling values exclusively from within each point's defined geometric neighborhood ($k$), explicitly preserving the underlying spatial sampling geometry while breaking local feature correlations.



\### 4. Observable Hierarchy



1\. \*\*Primary Observable:\*\* Localized Predictability Ratio ($R$)

2\. \*\*Uncertainty Observable:\*\* Confidence Interval of the Ratio ($\\text{CI}(R)$), derived directly from the permutation distribution variance.

3\. \*\*Temporal Observable:\*\* Predictability Trajectory ($R(t)$)

4\. \*\*Derived Observable (1st Derivative):\*\* Predictability Velocity ($\\text{d}R/\\text{d}t$)

5\. \*\*Derived Observable (2nd Derivative):\*\* Predictability Acceleration ($\\text{d}^2R/\\text{d}t^2$)



\### 5. The TRACEBIND Interpretation Layer (TIL) API



Every calculated output execution must pass through the TIL API to automatically generate a multi-tiered payload containing:



1\. \*\*Raw Measurement:\*\* $R \\pm \\text{CI}(R)$ and derived derivatives.

2\. \*\*Statistical Interpretation:\*\* Standard scientific characterization of spatial predictability relative to the reference distribution.

3\. \*\*Plain-English Interpretation:\*\* Jargon-free translation describing pattern structure.

4\. \*\*Evidence Boundaries:\*\* Strict enumeration of what the metric does and does not measure, explicitly checking for data quality artifacts.

5\. \*\*Recommended Next Measurements:\*\* Targeted list of domain-specific exogenous variables (e.g., humidity, wind vectors, optical depth) required by the investigator to independently test causal mechanisms.
